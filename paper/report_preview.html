Abstract

The N-Queens problem is a classic combinatorial benchmark in computer science that tests the limits of exact constraint-solving algorithms. Although classical backtracking struggles beyond moderate sizes (N > 30), modern solving paradigms offer exact solutions for significantly larger instances. In this paper, we develop a comprehensive exact SAT-based framework using PySAT to model and solve the large-scale N-Queens problem on board sizes up to N = 100 (10,000 Boolean decision variables and over 1.65 million clauses). To address the combinatorial clause explosion inherent in naive pairwise encodings, we systematically investigate five At-Most-One (AMO) encoding techniques: Pairwise (O(k2) clauses), Sequential Counter (Sinz 2005), Bitwise Binary encoding, Commander Variable (Klieber & Gao 2007), and 2-Product (Chen 2010). Furthermore, we conduct a cross-paradigm evaluation comparing four SAT solvers (MiniSat 2.2, CaDiCaL 1.5.3, Glucose 4.0, and Glucose 3.0) against Google OR-Tools CP-SAT (under both 1D all-different and 2D Boolean formulations) and 0-1 Integer Linear Programming (SCIP). Our extensive computational experiments reveal three key scientific findings: (1) SAT and CP-SAT scale with consistent efficiency, solving N = 100 in under 4 seconds, whereas ILP suffers a severe combinatorial breakdown and times out at N = 100 due to excessive fractional assignments in its linear programming relaxation; (2) compact AMO encodings such as 2-Product and Sequential Counter reduce the generated clause count by 92.9% compared to the pairwise encoding (from 1,646,900 to 116,636 clauses), substantially reducing memory overhead; and (3) an empirical encoding–solver interaction demonstrates that propagation-strong CDCL engines like MiniSat achieve the fastest runtime on Bitwise encodings, while Glucose displays sensitivity to auxiliary variables in product formulations.

1. Introduction

The N-Queens problem consists in placing n non-attacking queens on an n × n chessboard so that no two queens attack each other, i.e., no two queens share a row, a column, or a diagonal. It is a fundamental constraint satisfaction problem that has been studied for decades as a benchmark for exact combinatorial algorithms [1]. The search space of placing n queens on n2 squares contains nn configurations when assigning one queen per row. Traditional depth-first search with backtracking suffers from exponential time complexity (O(n!)), rendering naive exploration computationally intractable for n > 30.

Modern automated reasoning paradigms offer powerful alternatives. Three prominent exact methodologies are: (1) Boolean Satisfiability (SAT), which encodes constraints into Conjunctive Normal Form (CNF) solved by Conflict-Driven Clause Learning (CDCL) engines [2, 3]; (2) Constraint Programming (CP), which relies on high-level global constraints and domain filtering [4]; and (3) Integer Linear Programming (ILP), which formulates linear inequalities over 0-1 binary variables solved via branch-and-cut [5].

In this study, our contributions are as follows:

  • We implement five At-Most-One (AMO) cardinality encodings: Pairwise, Sequential Counter, Bitwise / Binary, Commander Variable, and 2-Product within a unified Python framework via PySAT [6].
  • We benchmark four modern CDCL solvers (MiniSat 2.2, CaDiCaL 1.5.3, Glucose 4.0, Glucose 3.0) on board dimensions up to N = 100 (10,000 cells).
  • We compare the SAT framework against exact CP and ILP baselines (Google OR-Tools CP-SAT and SCIP), analyzing why ILP suffers combinatorial degradation on large permutation puzzles.
  • We provide an open-source, fully reproducible benchmark repository.

2. Problem Formulation and Alternative Exact Paradigms

2.1. Problem Definition

Let (r, c) denote coordinates on an n × n chessboard with 0 ≤ r, c < n. An injective non-attacking placement of n queens requires:

∀r ∈ {0, …, n − 1},   ∑c=0n−1 xr,c = 1   (exactly one queen per row) (1)
∀c ∈ {0, …, n − 1},   ∑r=0n−1 xr,c ≤ 1   (at most one queen per column) (2)
∀diagonal D,   ∑(r,c)∈D xr,c ≤ 1   (at most one queen per diagonal) (3)

Falling diagonals have constant r − c ∈ {−(n−2), …, n−2}, while rising diagonals have constant r + c ∈ {1, …, 2n−3}.

2.2. Constraint Programming Formulation

Using integer variables Qr ∈ {0, …, n − 1} denoting the column index of the queen in row r, the problem is concisely formulated with three global AllDifferent constraints:

AllDifferent(Q0, …, Qn−1),   AllDifferent(Q0 − 0, …, Qn−1 − (n−1)),   AllDifferent(Q0 + 0, …, Qn−1 + (n−1)).

2.3. Integer Linear Programming & The LP Relaxation Bottleneck

In ILP, binary variables xr,c ∈ {0, 1} represent cell occupancy with row, column, and diagonal sums bounded by Equations (1)–(3). However, in the continuous LP relaxation where xr,c ∈ [0, 1], setting xr,c = 1/n for all cells satisfies every row sum (∑ 1/n = 1), column sum (∑ 1/n = 1), and diagonal sum (∑|D| 1/n ≤ 1) with zero violation. Consequently, the LP relaxation provides no valid dual bound to prune the Branch-and-Bound tree, causing standard MIP solvers to stall and time out on large instances (N ≥ 80).

3. Proposed SAT-Based Exact Approach

Each board cell (r, c) corresponds to a Boolean variable Xr,c mapped to integer r · n + c + 1. The condition "exactly one" per row and column is decomposed into At-Least-One (ALO): ∨c Xr,c and At-Most-One (AMO). We evaluate five AMO encodings:

  1. Pairwise: ∧i<j (¬li ∨ ¬lj). Requires O(k2) binary clauses with 0 auxiliary variables. For N = 100, diagonal constraints yield over 1.64 million clauses.
  2. Sequential Counter (Sinz [7]): Introduces k − 1 accumulator variables, reducing clause count to 3k − 4 (O(k) linear).
  3. Bitwise / Binary: Uses ⌈log2 k⌉ auxiliary bits to binary-encode the active queen index, yielding O(k log k) clauses.
  4. Commander Variable (Klieber & Gao [8]): Partitions literals into groups of size 3 and introduces group commanders recursively.
  5. 2-Product (Chen [9]): Arranges literals in a p × q grid (p ≈ √k, q ≈ ⌈k/p⌉), requiring only 2k + O(√k) clauses and 2√k auxiliary variables.

5. Conclusion

We presented a systematic investigation of exact SAT-based solving for the large-scale N-Queens problem up to N = 100. Our results demonstrate that SAT and CP-SAT substantially outperform 0-1 ILP on large permutation benchmarks. Furthermore, the 2-Product encoding achieves a 92.9% reduction in formula size over pairwise encodings, offering vital memory scalability for ultra-large boards.
